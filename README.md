# Holi 2025 · DY Patil — web concert

Martin Garrix's Holi 2025 show at DY Patil Stadium, rebuilt in Unity and playable in the browser.
Join a room code with friends: the host starts the concert for everyone, then dance (1-6), chat (Enter) and talk (hold V).

Play: https://gamedevayush.github.io/holi-concert/  (add `?room=CODE` to invite friends to the same room)

Built with Unity 2021.3 (WebGL), Photon Fusion 2 (shared rooms) and WebRTC voice.
